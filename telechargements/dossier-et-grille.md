# Le dossier de veille et sa grille

Fichier de contexte du cours « Veille professionnelle : le cas Decathlon », ISO Nantes, Licence 3, 2026-2027. À joindre à votre projet Claude.

## Le dossier

- Un dossier individuel, noté sur 20.
- 3 à 4 pages pour le corps du dossier, hors page de garde et annexes, en PDF.
- Plan :
  - Synthèse : le signal faible en deux phrases ;
  - 1. L’angle et la question de veille ;
  - 2. La méthode de recherche : mots-clés, requêtes, opérateurs, moteurs, source écartée ;
  - 3. L’analyse : les faits clés, les enjeux, ce que Decathlon doit surveiller ;
  - 4. La critique de l’IA et les limites ;
  - Annexes : les cinq sources exactes, la consigne de base envoyée à l’IA.

## La grille (sur 20)

- Recherche, 5 points : les requêtes booléennes intègrent correctement les opérateurs de base ; les filtres avancés sont pertinents ; la méthode de recherche est retracée dans le dossier.
- Sources, 5 points : des données récentes sur Decathlon ; des sources variées et fiables (presse économique, documents techniques, données publiques) ; les contenus publicitaires ou superficiels sont écartés.
- IA, 5 points : la consigne de base figure en annexe ; elle donne un rôle précis et un objectif clair ; les incohérences produites par la machine sont corrigées.
- Rédaction, 5 points : 3 à 4 pages, strictement ; le signal faible ressort clairement de la synthèse ; la mise en page est professionnelle et la lecture fluide.
