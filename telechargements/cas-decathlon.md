# Le cas Decathlon : faits publics et leurs limites

Fichier de contexte du cours « Veille professionnelle : le cas Decathlon », ISO Nantes, Licence 3, 2026-2027. À joindre à votre projet Claude. Faits relevés dans des sources publiques, consultées le 3 novembre 2026. Une source d’entreprise valorise l’entreprise : chaque fait se recoupe.

## Le communiqué de résultats annuels 2025 de Decathlon (2 avril 2026)

Source : communiqué de presse « Résultats annuels 2025 », Decathlon, Villeneuve-d’Ascq, 2 avril 2026. https://www.decathlon-united.media/

- Chiffre d’affaires 2025 : 16,8 milliards d’euros. Le volume d’affaires (GMV) est un autre indicateur : 20,7 milliards d’euros. Ne pas confondre les deux.
- Réseau : 1 902 magasins dans le corps du communiqué. La partie « À propos » du même communiqué donne 1 817 magasins. Le document se contredit : à signaler, jamais à choisir sans le dire.
- Réparation : 1 746 ateliers de réparation.
- Seconde main : 1,6 million de produits de seconde main vendus dans le texte, 1,58 million dans les chiffres clés. Offre présente sur 43 marchés.
- Bikeleasing : le communiqué mentionne l’acquisition de 65 % de Bikeleasing Group.
